# VASH 3.0 — Domain Knowledge Rules

## Reading Rules
Always read laws.md before any task.
Read relevant checklist for current artifact type.
Read tech_providers/ only for phase 3 activities and the activity-list Phase 7 activities that name them (Amended by 2.6).
Load only what current task needs — nothing more.

## Checklist Selection
Artifact activity → checklists/artifact.md
Manual step activity → checklists/manual_step.md
Code activity → checklists/code.md (Amended by 2.6; activity-list Phase 7)
AvA validation → checklists/ava.md
Prompt review → checklists/prompt.md
